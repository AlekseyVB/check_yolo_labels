# Windows: равномерная выборка и просмотр прямо в VS Code

## Файлы

- `check_yolo_labels.py` — обновлённый скрипт. Теперь спрашивает число кадров, если не передан `--samples`.
- `inspect_yolo_labels.ipynb` — запуск с вопросом и показом изображений прямо в VS Code.
- `requirements.txt` — зависимости Python.

Сохраните три файла в одну папку и откройте **эту папку** в VS Code. Нужен установленный Python 3.10 или новее. Для блокнотов установите расширения Microsoft **Python** и **Jupyter** в VS Code — это расширения редактора, их нет в requirements.txt.

## Создать виртуальное окружение

В терминале PowerShell в папке с файлами:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\requirements.txt
```

Если команда `py` отсутствует, а Python доступен через `python`:

```powershell
python -m venv .venv
```

Активация окружения не обязательна: приведённая команда установки явно использует Python из `.venv`. Поэтому менять политику выполнения PowerShell не нужно.

## Рекомендуемый вариант: блокнот

1. Откройте `inspect_yolo_labels.ipynb` в VS Code.
2. В **Select Kernel / Выбрать ядро** выберите Python из `.venv`.
3. Проверьте путь `DATASET` в ячейке. Сейчас указан ваш датасет на диске G:.
4. Нажмите ▶ у ячейки.
5. После проверки файлов программа спросит: **«Сколько файлов показать?»** Введите, например, `10` и подтвердите ввод.
6. В выводе ячейки появятся изображения: исходный кадр и его версия с рамками, затем следующая пара.

Если скрипт не найден, укажите в `SCRIPT_FOLDER` абсолютный путь к папке, где лежит `check_yolo_labels.py`. По умолчанию используется текущая рабочая папка блокнота.

## Как выбираются кадры

Файлы упорядочены по имени внутри разделов `train`, `valid`, `val`, `test` в этом порядке. Выборка охватывает весь этот список, а не первые N файлов и не случайные кадры.

Для M файлов и N образцов позиции в нумерации с нуля:

```text
round(i × (M − 1) / (N − 1)), i = 0 … N − 1
```

В коде применяется целочисленное округление к ближайшей позиции, при равенстве — вверх. Шаги могут отличаться на один файл: целые позиции не всегда делятся ровно.

Проверенный пример: **425 файлов, показать 10**:

```text
1, 48, 95, 142, 189, 237, 284, 331, 378, 425
```

Первый и последний файлы включаются всегда, если выбрано не меньше двух. При выборе одного показывается только первый — включить оба конца в один образец невозможно. Если количество задано параметром `--samples` и превышает число доступных файлов, будут показаны все доступные.

В отличие от предыдущей версии скрипт больше не подменяет один из равномерно выбранных кадров самым насыщенным по числу боксов.

## Альтернатива: Python-файл в интерактивном окне VS Code

Откройте `check_yolo_labels.py`, выберите интерпретатор `.venv`, затем выполните команду редактора:

**Jupyter: Run Current File in Python Interactive Window**

Можно также нажать **Run Cell** над первой строкой `# %%`. Скрипт спросит число кадров и покажет изображения прямо в интерактивном окне. Для другого датасета измените `DEFAULT_DATASET` в начале файла.

## Если запускать из обычного терминала

```powershell
.\.venv\Scripts\python.exe .\check_yolo_labels.py
```

Скрипт тоже задаст вопрос, но терминал сам картинки не рисует. После выполнения откройте в VS Code созданный файл:

```text
manual_preview\preview.ipynb
```

Изображения уже встроены в этот блокнот: для просмотра не требуется повторно запускать код. При желании доступна также HTML-галерея.

Чтобы пропустить вопрос и сразу выбрать десять кадров:

```powershell
.\.venv\Scripts\python.exe .\check_yolo_labels.py --samples 10
```

Чтобы изменить пути:

```powershell
.\.venv\Scripts\python.exe .\check_yolo_labels.py --dataset "G:\Мой диск\BusCam-for-DataSet\CH01-20260926-dataset\people_india_bus-1.yolo26" --out ".\new_preview"
```

## Безопасность и проверка

Исходные фотографии и `.txt` не изменяются. Результаты сохраняются отдельно; писать внутрь датасета скрипт запрещает. Повторный запуск в ту же папку обновит свои результаты, но не удалит устаревшие картинки прежней выборки. Для новой независимой проверки задайте новый `--out`.

Проверено на Windows: обработка всех 425 изображений, интерактивный ввод числа 10, выбор правильных позиций, создание десяти пар картинок и блокнота со встроенными изображениями. Логика выборки также проверена на 10 200 сочетаниях количества файлов и образцов. Отображение в вашей установленной версии VS Code ещё не проверялось.

Документация VS Code: https://code.visualstudio.com/docs/python/jupyter-support-py и https://code.visualstudio.com/docs/datascience/jupyter-notebooks.
